# Functionality and performance audit, 2026-11-23

A read-only review of the tree at 0.7.2 (`6fe1e11`), followed by the fixes released as 0.7.3. File and line references are to the 0.7.2 tree.

The review read code and documentation; it did not build, run or measure anything. Every mechanism below was confirmed by reading the code. Every duration is an estimate, not a measurement. The existing macOS benchmark (`benchmarks/macos/results/latency-12.md`) predates this review and covers Wry on macOS only.

Status is one of:

- **Fixed in 0.7.3** — changed and covered by a test.
- **Partly fixed** — the part named is done; the rest is open.
- **Open** — not changed.

## Summary

The Wry request path was already tight: the bridge is injected once per document, each call sends a few hundred bytes, and results return without polling. The costs and defects were in the layers around it.

## Performance findings

| # | Finding | Where | Status |
| - | ------- | ----- | ------ |
| 1 | `getByRole` took a full-document snapshot on every action and every assertion poll, cleared all refs and overwrote the `diff` baseline. Estimated 5–20 ms per action on a 2–5k element page, against about 0.5 ms for a CSS locator. | `packages/playwright/src/window.ts:1292` | Fixed in 0.7.3: `query` has a `role` dimension and the client uses it. |
| 2 | CEF re-sends the whole bridge (about 95 KB) and makes two extra CDP round trips on every eval; the html-to-image bundle re-executes each time. Estimated 1–3 ms per call. While a route exists, every fetch is paused and answered from a newly spawned thread. | `crates/tauri-plugin-hasgard/src/cef.rs:655`, `:878`, `:604` | Open |
| 3 | One connection handled requests strictly in series, so a pending `wait`, `watch` or screenshot held every later request, including those for other windows. `watch` followed by an action could only end in the watch timing out. | `crates/tauri-plugin-hasgard/src/server/mod.rs:78` | Fixed in 0.7.3: requests are pipelined, ordered per window. |
| 4 | Text queries read `textContent` for every element and filtered matches pairwise, quadratic in the match count. `getName` reads a whole subtree to keep 50 characters. | `crates/tauri-plugin-hasgard/js/bridge.js:833`, `:660` | Partly fixed: text queries walk once. `getName` is open. |
| 5 | Every `press` on Windows and Linux slept a fixed 80 ms, even with focus already in place, and did not verify that focus arrived. | `crates/tauri-plugin-hasgard/src/handler.rs:17`, `:554` | Partly fixed: Windows confirms the foreground window and waits only when focus moved. Linux keeps the 80 ms settle and no verification. |
| 6 | Client-side waiting polled every 50 ms and re-resolved the locator each time. | `packages/playwright/src/expect.ts:3`, `window.ts:1187` | Partly fixed: polling steps 10, 20, 50 ms. An in-page wait for query, filter and index locators is open. |
| 7 | Console capture runs `JSON.stringify` on every argument as a probe, captures a stack per call, and retains the original objects for up to 500 entries. | `crates/tauri-plugin-hasgard/js/bridge.js:47`, `:82` | Open |
| 8 | A DOM screenshot is copied about seven times as base64 and rasterised on the page's main thread. | `bridge.js:1975`, `eval.rs:259`, `handler.rs:221` | Partly fixed: Wry on Windows takes composited pixels through WebView2 instead of rasterising in the page. The double encoding and the absence of an `output_path` mode are open. |
| 9 | MCP opens a new connection per tool call. About 0.1–0.3 ms. | `crates/tauri-hasgard-mcp/src/mcp.rs:161` | Open; not worth prioritising. |

Checked and found sound: bounded buffers for logs, network, routes, watch, storage and forms; `diff` is linear; CSS locators resolve and act in one round trip; selector `wait` and `watch` use `MutationObserver`; `screenshot_native` writes by path with an atomic rename.

## Absent capabilities

None of these were added: downloads, clipboard, cookies, native OS dialogs, `beforeunload`, window management (resize, move, close), Tauri event emit and listen, viewport sizing, key hold, multi-select options, wait for URL or load, tracing, cross-origin frames on Wry, pointer-sequence drag.

## Verification of the 0.7.3 fixes

- Rust: 157 plugin, 132 CLI and 66 MCP tests pass on Windows; CI passes on macOS and Windows with all features.
- JavaScript: 149 bridge tests and 118 package tests pass.
- Native: the fixture suite passes on Windows, 62 run and 18 skipped as macOS only, including four tests added for composited screenshots, a pending `watch`, stale refs and the new assertions.
- Not exercised natively: CEF on Windows was compiled and tested in CI only, not run locally.
